改善点

検証

health、セッション、イベント作成、公開読取、匿名回答、主催者読取、削除までを一つの smoke verifier で確認できます。合成 ID と capability を使い、失敗時や割り込み時も cleanup を試みます。

運用

保守

Worker の責務を追いやすい

route、policy、events、responses、cleanup の境界をコードと構造テストで確認します。テストは通常の npm test に入り、分割が戻ったときに検知できます。

UNVERIFIED staging token を必要とする実データ smoke の全行程。秘密値はこのレポートへ記録していません。
