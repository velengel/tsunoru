# ADR 0063: 非同期Codexレビューはリポジトリの監視スクリプトで完了を待つ

## context

GitHubのCodexレビューはPRをReadyにした後に非同期で実行される。手動でコメントを何度も確認すると、レビュー完了前にPR状態を判断したり、同じ指摘を分割して処理したりする危険がある。

## decision

PR番号を受け取った監視スクリプトでCodexレビューサマリーの完了をポーリングし、完了時に対象HEADとレビュー内容をまとめて出力する。

## rejected options

- 手動で`gh pr view`を繰り返す: 確認漏れと早期判断を防げない。
- コメントごとに即時対応する: 既存のバッチ判断・2往復上限に反する。
- GitHub Actionsだけで完了判定する: ローカルの判断ログや現在のworktree状態と結び付かず、個人開発のレビュー収束には過剰である。

## consequences

監視にはGitHub CLIの認証とPython 3が必要である。タイムアウト時は未完了として終了し、レビュー完了を推測しない。スクリプトは読み取り専用でPRやリポジトリを変更しない。
