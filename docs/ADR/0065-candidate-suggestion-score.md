# ADR 0065: 候補日時は○を2点、△を1点として主催者画面で強調する

## context

回答集計では全員の○が理想だが、現実には候補が完全一致しない。主催者が候補を比較できるよう、○を最優先しつつ△も情報として加点する必要がある。

## decision

候補日時ごとに○を2点、△を1点、×を0点として合計し、最高得点の候補を強調表示する。

## rejected options

- ○の数だけで順位付けする: △が多い候補の差を表現できない。
- ○・△・×を同じ点にする: ×を含む候補を過大評価する。
- 自動で日程を確定する: 強調表示は判断補助であり、主催者の決定権を奪う。

## consequences

同点の候補は同じ強調状態になる。スコアは表示上の補助情報であり、回答データや認可境界は変更しない。
