# ADR 0022: 集まる点をTSUNORUのfaviconにする

## context

TSUNORUにはfaviconがなく、ブラウザーのタブがプロダクト固有の見た目を持っていない。

TSUNORUは、多数決や自動推薦で開催日を決めるサービスではない。
参加者の都合をつのり、集まった回答を材料に主催者が一つの開催日を決める。

## decision

- **TSUNORUマーク**は、三つの明るい点が一つの橙色の点へ集まる形とする。複数人の都合が開催日へ集まる流れを表す。
- 背景は画面の主要操作と同じ深緑 `#365c40`、明るい点と線は生成り `#fffefa`、集まる先はfocus色と同系の橙 `#a43f28` を基準にする。
- 深緑を正方形の外周まで敷き、タブ背景の明暗にかかわらず同じ色と輪郭を保つ。
- 文字、数字、カレンダーの格子、check mark、人物の顔を入れない。16px相当で意味のない細部を増やさない。
- 最終assetは64px四方のRGB PNGとし、Dioxusの `asset!` と `document::Link` から参照する。
- 生成時の構図は正方形中央配置、左右対称、太い経路、余白を十分に取ったflatな図形とする。

## rejected options

### カレンダーだけを描く

日程調整は伝わるが、都合をつのって一つの開催日へ集めるTSUNORUの流れを表せないため採用しない。

### `T`の文字を使う

小さく表示しやすい一方、プロダクトの働きではなく名称の頭文字だけを示すため採用しない。

### ○、△、×をすべて描く

回答方法を直接表せるが、16pxでは形が潰れ、faviconが回答入力だけを代表してしまうため採用しない。

### SVGを手作業で配信する

小サイズへ調整しやすいが、今回の生成bitmapと別の視覚的正本が生まれる。
初期版は一つのPNGを正本とし、ブランド展開が必要になった時点でvector化を判断する。

### 角丸の外側を透明にする

タブ背景になじむ一方、生成画像では外周だけでなく深緑の内側にも意図しない透明部分が生じた。
小さな表示での明瞭さを優先し、深緑を外周まで敷く。

## consequences

- ブラウザーのタブでTSUNORUを色とシルエットから見分けられる。
- マークは「回答を集める」から「開催日を決める」までを一つの流れとして示す。
- 64px PNGはfavicon用途には足りるが、ホーム画面iconや印刷物には別assetが必要になる。
- 生成結果は確定したPNGが正本であり、同じpromptから同じpixelを再生成できるとは限らない。
- 外周まで不透明なため、ブラウザーのタブでは正方形として表示される。
