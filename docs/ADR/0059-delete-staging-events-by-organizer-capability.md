# ADR 0059: 試用イベントを主催者権限で削除する

## context

公開stagingの書き込み検証では、合成イベントと回答を作成した後に、検証で所有したデータを確実に片づける必要がある。イベントIDだけで削除できると、共有URLを知る第三者が破壊的操作を実行できる。D1にはイベント、候補、回答、回答選択が分かれて保存されているため、関連行を一括で削除する必要がある。

## decision

`DELETE /api/events/:id` を主催者capabilityの照合と同一D1 batchによる関連行削除で実装する。

## rejected options

- イベントIDだけで削除する：共有URLだけで破壊的操作を許す。
- 回答や候補を個別に削除する：関連行の残留と部分削除を招く。
- 検証後にD1管理者操作だけで削除する：アプリが保証する所有権境界を検証できない。

## consequences

主催者だけがイベント全体を削除でき、回答・候補・回答選択も同じbatchで削除される。削除APIは限定stagingの運用・検証用であり、復元機能、個別失効、一般公開向けの保持ポリシーは提供しない。削除要求の応答は成功時 `{\"deleted\":true}`、権限不一致は403、存在しないイベントは404とする。
