# ADR 0075: D1で入口ごとの固定window rate limitを記録する

## context
一般公開前のWorkerは、共有staging鍵を通過した作成・回答・読取を無制限に受け付ける。Workerインスタンス内メモリだけでは分散実行を横断して制限できない。

## decision
作成（60件）・回答（120件）・読取（240件）を60秒固定windowごとに、匿名化した送信元識別子と入口名でD1に記録し、超過時は`429 rate_limited`と`Retry-After`を返す。

## rejected options
Workerメモリだけの制限はインスタンス間で共有されず、IPやcapabilityの生値をログ・キーにする案は秘密と個人情報の露出を増やすため退ける。

## consequences
D1書き込みと競合制御の負荷が増え、NAT共有では利用者が同じ制限を受ける。Cloudflareの送信元ヘッダーをハッシュ化し、秘密値は保存・応答・ログへ出さない。DELETEと認証専用入口は認証済みのためこの制限対象外とする。閾値は初期運用値で、公開前に実測して再調整する。
