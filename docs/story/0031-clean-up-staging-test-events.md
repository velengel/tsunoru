# Story 0031: stagingの検証イベントを安全に削除する

## context

公開stagingで書き込み操作を検証するため、検証者が所有する合成イベントを、関連する回答まで含めて後始末できる必要がある。共有URLやイベントIDだけでは削除できない境界を保つ。

## definition of done

- [x] 主催者capabilityを要求する削除APIがある。
- [x] イベント、候補、回答、回答選択を一つのD1 batchで削除する。
- [x] 間違ったcapabilityは403、存在しないイベントは404になる。
- [x] 削除後にイベントと関連行が残らないことをローカル統合テストで確認する。
- [ ] 実URLで認証から作成・回答・集計・削除まで確認する。

## to do

- [x] 失敗するユーザー観測テストを先に追加する。
- [x] Worker routeとD1削除batchを実装する。
- [x] ローカルWorker統合テストとbuildを実行する。
- [ ] stagingへ反映し、合成データの実URL検証後に削除する。

## concern

削除は不可逆であるため、主催者capabilityを知らない利用者には許可しない。一般公開での削除・復元・保持期間は別issueで判断する。実URL検証は専用D1の合成データだけを対象にする。
