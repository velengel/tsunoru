# Story 0035: 保存済み匿名回答を同じブラウザーから編集する

## context
Issue #17。回答者が保存済み回答を同じブラウザーから再入力できるようにする。公開イベントIDや回答者名だけでは認可せず、ブラウザーに保存したresponse capabilityを使う。

## definition of done
- 保存済み回答の回答者名クリックから回答フォームを再表示できる。
- 同じresponse capabilityで回答内容を更新できる。
- capabilityなし・別イベント・不正な候補集合は拒否し、既存回答を変更しない。
- 更新失敗時は編集入力を保持する。
- 回答送信と編集の競合・再送・決定済みイベントをテストする。Worker pilotに決定状態が未実装のため、決定済み境界は後続Storyへ保留する。

## to do
- [x] 更新APIと認可を実装する
- [x] 回答フォームの再編集導線を実装する
- [x] 失敗時保持と境界テストを追加する
- [ ] 実URL・ブラウザー確認を行う

## concern
response capabilityの漏えいは他人による回答変更につながる。公開event ID、回答者名、response IDは単独で認可に使わない。日程決定後の編集方針は既存の不変性を維持する。
